# 存量与不良资产商学院 - 网站原型设计

> 设计日期：2026-05-03
> AI团队协作完成

## 📋 项目概述

专为存量与不良资产行业打造的综合性商学院平台，集课程学习、会员服务、AI营销工具、业务撮合于一体。

## 🎯 目标用户

- **从业者**：存量与不良资产处置方、服务方
- **投资者**：个人投资者、机构投资者

## 💰 会员体系

| 等级 | 价格/年 | 目标用户 |
|------|---------|---------| 
| 🥈 白银会员 | ¥5,980 | 入门从业者 |
| 🥇 黄金会员 | ¥26,800 | 中高端从业者 |
| 💎 钻石会员 | ¥59,800 | 区域合伙人 |
| 👑 联合创始人 | ¥198,000 | 顶级资源方 |

## 🏗️ 功能模块

### 1. 营销工具
- 🎬 AI视频制作（即梦/小火API接入）
- 🖼️ AI图文生成
- 📝 文案库
- 🎪 沙龙申请/展示
- 💬 私域沟通群

### 2. 业务系统
- 📦 自有项目库
- 🤝 合作申请/提案
- 👥 OPC团队撮合
- 💰 配资申请/展示
- 🎓 专家邀约
- 🔗 资源链接

### 3. 商学院课程
- 📚 线上课件
- 📅 线下会议
- 📊 案例库
- 🎥 直播室
- 💭 学习分享
